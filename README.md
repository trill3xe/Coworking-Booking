# WORKSPACE

Веб-приложение для каталога и бронирования рабочих пространств. Использует Firebase Authentication для учетных записей и Firestore для каталога, бронирований, пользователей и отзывов.

## Возможности

- Каталог с поиском, категориями, сортировкой и постраничной загрузкой.
- Подробная страница пространства с бронированием и отзывами.
- Личный кабинет с историей бронирований и управлением отзывами.
- Админ-панель: управление пространствами, бронированиями, пользователями и отзывами.
- Обновления в реальном времени через Firestore `onSnapshot`.

## Структура проекта

- `public/` — страницы, стили и клиентский JavaScript.
- `config/firestore.rules` — правила доступа к Firestore.
- `firestore.indexes.json` — составные индексы запросов.
- `FIRESTORE_SCHEMA.md` — схема коллекций, полей и связей.
- `scripts/seed.js` — необязательная загрузка демонстрационных данных.

## Локальный запуск

Установите зависимости и запустите статический сервер:

```sh
npm install
npx http-server public -p 8080
```

Откройте `http://localhost:8080`. Конфигурация Firebase-клиента находится в `public/js/firebase-config.js`. Для входа и сброса пароля включите Email/Password в Firebase Authentication и добавьте домен сайта в список разрешенных.

## Проверки

```sh
npm test
```

Команда проверяет синтаксис клиентских JavaScript-модулей и серверных скриптов Node.js.

## Демонстрационные данные

При необходимости загрузите каталог в настроенный проект Firebase:

```sh
npm run seed
```

Команда требует `scripts/serviceAccountKey.json` и записывает демонстрационные документы в Firestore. Проверяйте выбранный проект перед запуском. Файл service account содержит секретный ключ: не публикуйте и не добавляйте его в репозиторий.

## Публикация в Firebase Hosting

После входа в Firebase CLI разверните сайт и правила:

```sh
firebase deploy --only hosting,firestore:rules --project coworking-booking-61599
```

Статические файлы сайта берутся из `public/` согласно `firebase.json`.
